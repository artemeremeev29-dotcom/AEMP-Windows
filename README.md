# 🧡 AEMP Windows

**AEMP — Enjoy the sound.**

AEMP — музыкальный проигрыватель для Windows, являющийся частью проекта AEMP.

Наша цель — создать удобный, функциональный и красивый музыкальный плеер с возможностью персонализации и дальнейшего расширения.

## 🚀 Возможности

- 🎵 Воспроизведение музыки
- 🎚️ Эквалайзер и аудиоэффекты
- 🎨 Настройка внешнего вида
- 📂 Работа с музыкальными файлами
- 🔊 Управление воспроизведением

*Список возможностей будет расширяться.*

## 📦 Версии

В разработке используются следующие типы сборок:

- **Alpha** — раннее тестирование.
- **Beta** — открытое тестирование.
- **Stable** — стабильные релизы.

## 💻 Совместимость

Платформа: Windows.

Подробные системные требования будут опубликованы позднее.

## 🛠️ Разработка

AEMP Windows активно развивается. Возможны ошибки и нестабильная работа тестовых сборок.
